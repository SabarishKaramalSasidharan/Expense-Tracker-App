One-time setup needed

This app needs a free Firebase project to store and sync data between phones. Takes about 5 minutes, no credit card.

  1. Go to console.firebase.google.com and create a project (any name, e.g. "household-expenses").
  2. In the project, open Build → Firestore Database → Create database → start in production mode → pick any region.
  3. Open Build → Authentication → Get started → enable the Anonymous sign-in provider.
  4. In Firestore → Rules tab, replace the contents with this and click Publish: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  5. Back in Project settings (gear icon) → scroll to "Your apps" → click the </> (Web) icon → register an app (any nickname) → copy the firebaseConfig object it shows you.
  6. Send that config to Claude, or paste it yourself into index.html in place of the FIREBASE_CONFIG placeholder near the top of the script, then save and push.
